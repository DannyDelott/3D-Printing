# Model rights and provenance

No repository-wide license is granted for the model files in this collection.

Some 3MF projects were created from or alongside third-party models. A 3MF can retain embedded author, source, license, description, and auxiliary files even after the plate has been edited. Those embedded records should be preserved and checked before a model is published or redistributed.

Known imported provenance found during the initial repository inventory:

- `projects/gridfinity/jae-small-filing-cabinet/models/bins.3mf` contains attribution to **Gridfinity Extended** by ostat and embedded BY-SA metadata.
- `projects/ping-pong-ball-tail-attachment/models/ping-pong-ball-tail-attachment.3mf` contains embedded 3DBenchy source material and Creative Tools attribution. The printable objects appear to be attachment variants, but the entire 3MF should be reviewed before public redistribution.

- `projects/cardboard-can/models/cardboard-can.3mf` preserves “Lightweight Recycled Box | Stackable” attribution to sdaendi, the JSBG print profile, and Standard Digital File License metadata. See its project README for both related MakerWorld links.

Project READMEs record the information currently known about each file. Add source links and exact license terms whenever a model's origin is known.
