# Ping-pong ball tail attachment

A collaboration project containing side-clip tail attachment variants for a 40 mm ping-pong ball.

## Files

| File | Notes |
| --- | --- |
| `models/ping-pong-ball-tail-attachment.3mf` | Five-plate Bambu Studio 2.6 project with loose and tight clip variants |

## Site preview

The site shows one attachment from plate 1 (build object 2, mesh object 1 in `3D/Objects/object_3.model`). `site/assets/tail-single.stl` preserves that mesh without the other plates or copies. The matching PNG is rendered with the site viewer. The downloadable 3MF retains all five plates and variants.

## Provenance

The 3MF contains embedded 3DBenchy auxiliary material and Creative Tools attribution inherited from an imported source project. Review the full archive before redistributing it publicly.
