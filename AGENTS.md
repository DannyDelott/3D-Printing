# 3D Printing

After accepted project or site changes, commit directly to `main` and run `python3 site/build/publish.py`. The user does not review code or PRs for this repository. Verify the GitHub Pages deployment and live `build-info.json` before reporting publication complete.

When adding or revising a model, update its `site/catalog.json` entry and keep the preview, dimensions, status, and selected downloads on the same revision. Follow [site/README.md](site/README.md) for the catalog and publishing process.

Keep the site practical: project names, revisions, specifications, print instructions, validation, attribution, and downloads. Preserve the compact index layout; omit promotional copy, narrative sections, footers, and prototype status text.
